# 单店美容收银台需求文档

日期：2026-10-16  
适用：一家门店、一台主收银电脑、控制改造成本  
依据：`tmp/20261016-115615.jpg`、`tmp/20261016-115625.jpg`

## 1. 目标

把门店日常做成「认人、开卡、核销、对账」一条链路。店员在收银台能看清这个客人是谁、还剩什么、这次做什么，每一笔钱和次数都能对上。

本期只服务这一家店。不做连锁、不做会员小程序、不做短信或微信自动发送。

## 2. 谁在用

| 角色 | 做什么 |
| --- | --- |
| 收银员 | 开单、认会员、开卡充值、划卡、收款、打印小票 |
| 护理师 | 写当次护理日志，查看过敏和皮肤备注 |
| 店长 | 改等级折扣、管标签、处理转卡退卡冻结、看变更日志 |

登录沿用现有账号。店长才能做退卡、转卡、冻结、手工改积分。

## 3. 现状（本仓库）

本仓库是 Electron + Vue 2 + Element UI 的 fuint 收银客户端，业务数据走远端 `backendApi`。

已经有、本期继续用：

- 商品收银、购物车、结算、小票打印、员工绑定
- 会员：姓名、手机、性别、生日、等级、状态、备注
- 单一余额充值、积分调整、卡券核销（含次数型券）
- 订单列表

对照两张需求图，缺这些：

| 需求 | 现状 |
| --- | --- |
| 皮肤状况、过敏备注 | 只有一段通用备注 |
| 每次护理写日志 | 无 |
| 消费、剩余卡、储值、到店频率放在一页 | 分散在会员列表和订单里 |
| 普通 / 银 / 金 / 钻及不同折扣 | 有等级字段，没有这四档和结算折扣规则 |
| 积分累计、兑换项目或产品 | 能手工改积分，没有兑换 |
| 客户标签、回访、生日提醒 | 无 |
| 储值本金 / 赠金分开记账 | 充值方案能配赠送金额，账上仍是一个余额 |
| 计次 / 疗程卡、剩余次数、到期提醒 | 次数型卡券只能核销，不是疗程卡 |
| 限时卡、体验卡、活动礼包卡、闺蜜共享卡 | 无独立卡种 |
| 开卡、充值、转卡、退卡、冻结及变更日志 | 只有充值和卡券核销，没有完整流水 |

次数型卡券不拿来当疗程卡。它没有本金赠金、转卡退卡冻结，也没有按卡的变更日志。

## 4. 本期不做

- 第二家门店、跨店划卡、总部报表
- 会员自己用的小程序或 App
- 短信、微信模板消息、自动外呼（生日和到期只在收银台里提醒，由店员打电话或当面说）
- 重做商品、扫码支付、小票打印
- 更换 Vue 3 或重写 Electron 外壳
- 复杂营销：拼团、分销、优惠券工厂

## 5. 功能需求

### 5.1 客户档案

必填：姓名、手机号。手机号在本店唯一。

选填：生日（日期）、性别、皮肤状况、过敏备注、通讯地址。

皮肤状况用短文本，例如「干敏、T 区出油」。过敏备注单独一栏，收银和护理时都要能看见，不能藏在长备注里。

会员状态仍为正常 / 禁用。禁用后不能开单、不能划卡。

### 5.2 护理日志

每一次到店做护理，必须能记一条日志，字段：

- 日期时间（默认现在）
- 护理项目（可多选本店项目，也可手写一项）
- 护理师
- 本次皮肤情况
- 做了什么、客人反应
- 下次建议

日志只追加，不物理删除。写错了由原护理师或店长追加一条更正，保留原记录。

### 5.3 全部历史（会员详情一页看完）

打开会员，同一页展示：

- 档案摘要：姓名、电话、生日、等级、皮肤、过敏、标签
- 储值：本金余额、赠金余额
- 每张未用完的卡：名称、剩余次数或剩余额度、到期日
- 消费记录：时间、项目或商品、实付、支付方式（现金 / 扫码 / 储值 / 划卡 / 积分）
- 到店频率：近 30 天次数、近 90 天次数、最近到店日

到店一次的定义：当天有消费单，或有护理日志，或有划卡，同一天只计 1 次。

### 5.4 会员等级

固定四档，由低到高：普通、银卡、金卡、钻卡。新会员默认普通。

每档一个折扣，作用于划价后的项目和商品原价，例如金卡 8.5 折。折扣由店长在设置里改，立即对之后的新单生效，不改历史订单。

结算顺序：

1. 先按会员等级打折
2. 再用积分或卡（若本单使用）
3. 储值、扫码、现金支付剩余金额

折扣后金额四舍五入到分。

### 5.5 积分

- 实付现金、扫码、储值本金，每 1 元积 1 分，不满 1 元不计
- 赠金支付、划卡核销不积分
- 退款或退卡退回的本金，按原单扣回对应积分，积分不够扣到 0
- 店长可手工加减积分，必须填写原因，写入变更日志

兑换：店长维护可兑换项（项目或产品、所需积分、是否上架）。兑换时扣积分、生成 0 元兑换单、写日志。积分不足不能兑换。

### 5.6 标签、回访、生日

标签是本店短词，可手工贴上或撕下，例如「敏感肌」「高消费」「很久没来」。

系统每天打开收银台时自动维护两个标签（店长可改规则，默认如下）：

- 高消费：近 90 天实付合计 ≥ 3000 元
- 很久没来：曾经到店，且最近到店早于 60 天前

「敏感肌」只手工打，不自动打。

收银台首页有「今日待办」：

- 今天生日的会员（按月-日，不论年份）
- 7 天内到期且仍有剩余的卡
- 带「很久没来」标签的会员，最多列 50 人

待办只提醒，不发送消息。店员可标记「已回访」并写一句结果，记在该会员名下。

### 5.7 卡种

每张卡属于一名持卡人，有卡号、状态、开卡时间。状态：正常、冻结、已退、已用完、已过期。

| 卡种 | 规则 |
| --- | --- |
| 储值卡 | 一个会员一张。余额拆成本金、赠金。充值增加本金，并按方案增加赠金 |
| 计次 / 疗程卡 | 绑定一个项目，例如面部护理 12 次。到店核销扣 1 次或指定次数，显示剩余次数。可设到期日 |
| 限时卡 | 在起止日期内，绑定项目不限次数。过期不能核销 |
| 体验卡 | 计次卡的一种，默认 1 次，不可充值加次 |
| 活动礼包卡 | 一次开卡包含多项，每项各自剩余次数，核销时选定其中一项 |
| 闺蜜共享卡 | 计次或限时。除持卡人外最多再绑 3 个本店会员。共享人到店可核销，扣的是同一张卡的次数 |

冻结期间不能核销、不能充值。解冻后恢复，到期日不顺延。

### 5.8 卡业务与变更日志

每一种操作都写一条不可改的变更日志：时间、操作人、会员、卡、动作、变动前、变动后、原因。

| 动作 | 规则 |
| --- | --- |
| 开卡 | 收款后生成卡。计次卡记录购买次数和实收金额；体验卡次数为 1 |
| 充值 | 仅储值卡、计次卡。储值：本金增加实收，赠金按当时方案；计次：增加次数。体验卡不能充值 |
| 转卡 | 储值把指定本金和赠金转到另一会员的储值卡；计次把剩余次数转到另一会员的同项目新卡或已有卡。转出方扣减，转入方增加，两边各记一条日志 |
| 退卡 | 储值只退剩余本金，赠金清零。计次按「实收金额 / 购买次数 × 剩余次数」算应退，四舍五入到分，赠送次数不退钱。退卡后状态为已退，不能再核销 |
| 冻结 / 解冻 | 只改状态，余额和次数不动 |
| 核销 | 计次减次数；限时只记使用、不减次数；储值按 5.9 扣款 |

日志用于对账。界面按卡、按会员都能查到。

### 5.9 储值扣款顺序

消费使用储值时：先扣本金，本金不足再扣赠金。退款退回储值时，按原扣款构成退回（扣了多少本金就退多少本金）。

会员详情和收款页同时显示两个数，不合并成一个「余额」作为唯一账。

### 5.10 收银怎么用这些能力

现有开单流程保留。认会员之后：

- 顶栏显示等级、折扣、过敏备注、本金、赠金、可用卡
- 结算时可选：等级折扣（默认勾上）、划某张卡、储值、积分兑换、扫码或现金
- 划计次卡时选择次数，不能超过剩余次数
- 有过敏备注时，划卡和结算前弹出一次确认

小票增加：会员姓名、等级、本次扣次或扣储值（本金、赠金分开）、剩余次数或剩余本金赠金。

## 6. 数据（单店一台电脑）

新数据放在收银电脑本地 SQLite，用会员在 fuint 里的 `memberId` 关联。商品、支付、打印仍走现有接口。

| 表 | 存什么 |
| --- | --- |
| member_profile | memberId、皮肤状况、过敏备注 |
| member_tag | 标签名、会员、来源（手工 / 自动） |
| nursing_log | 护理日志 |
| followup | 回访记录 |
| card | 卡种、状态、项目、总次数、剩余次数、到期日、持卡人 |
| card_share | 闺蜜共享人 |
| card_ledger | 变更日志，含本金赠金变动前后 |
| stored_value | 每个会员一条：本金余额、赠金余额 |
| point_ledger | 积分变动 |
| redeem_item | 可兑换项目或产品 |
| grade_discount | 四档折扣 |
| recharge_plan | 充值多少送多少赠金 |

金额用分（整数）存储。删除会员时不删日志和卡流水。

## 7. 验收

用下面场景走一遍即视为本期需求完成：

1. 新建会员，填写皮肤和过敏。再次开单时过敏备注可见。
2. 开一张面部护理 12 次卡，核销 1 次，剩余显示 11，日志能看到扣次前后。
3. 储值充 1000 送 200。花 300，本金变 700、赠金仍 200。再花 800，本金 0、赠金 100。
4. 金卡会员买原价 100 元项目，按该档折扣成交，积分只按实付累计。
5. 把剩余次数转到另一会员，两边余额和两条日志一致。
6. 退储值卡只退剩余本金，赠金变 0，卡状态为已退。
7. 今天生日的会员、7 天内到期的卡，出现在今日待办。不发生外发短信。
8. 给会员打上「敏感肌」，列表能按标签筛到。
